MoaDock / 모아독 — 소스 비공개 무료 Windows 앱

실행 방법
ZIP 전체를 쓰기 가능한 새 폴더에 풀고 MoaDock.exe를 실행하세요.
Python 별도 설치는 필요하지 않습니다. _internal 폴더를 포함한 전체 구성을 유지하세요.
기존 사용자는 먼저 설정과 메모를 백업하고 이전 앱을 트레이에서 종료하세요. 기존 폴더 위에 덮어쓰지 마세요.

사용 조건
개인·기업·학교·공공기관의 합법적인 무료 사용과 조직 내부 설치를 허용합니다.
후원은 자율입니다. MoaDock 자체 소스는 공개하지 않습니다.
전체 조건은 LICENSE.txt, 외부 구성요소는 THIRD_PARTY_NOTICES.md를 확인하세요.
공식 전체 배포본의 무상 재배포 시 사용 조건·고지·외부 대응 소스도 함께 제공해야 합니다.

Qt / 7-Zip 고지
이 앱은 Qt/PySide6/Shiboken 및 7-Zip을 사용합니다. 각 구성요소의 LGPL 등 라이선스는 유지됩니다.
MoaDock의 조건은 외부 라이브러리의 사용·수정·재배포·교체·재연결 및 그 디버깅에 필요한 역공학을 제한하지 않습니다.
라이브러리 교체는 LIBRARY_REPLACEMENT.md, 대응 소스는 SOURCE-ACCESS.md를 확인하세요.
외부 소스 ZIP에는 MoaDock 자체 소스코드가 들어 있지 않습니다.

FFmpeg 구분
영상 재생용 Qt FFmpeg DLL은 포함되어 있습니다.
화면 녹화용 ffmpeg.exe는 포함하지 않으므로 별도 설치 후 PATH에 추가해야 합니다.
사용자가 별도로 설치한 FFmpeg 빌드는 해당 빌드의 라이선스를 확인하세요.
공식 다운로드 안내: https://ffmpeg.org/download.html

개인정보와 제한
사용자가 번역 전송 버튼을 누르면 확인한 텍스트가 외부 Google 웹 번역기로 전달됩니다.
이 배포본에는 사용자 설정·메모·문서·캡처가 포함되어 있지 않습니다.
HWP 재저장·XLSX 수식 자체 계산·PDF OCR·영상 편집·macOS·MCP/API는 지원하지 않습니다.
실제 프린터 출력 및 모든 캡처·코덱·다중 모니터 환경의 동작을 보장하지 않습니다.
코드 서명되지 않은 베타입니다. 공식 배포처와 SHA256SUMS.txt를 확인하고 조직의 보안 정책을 따르세요.
